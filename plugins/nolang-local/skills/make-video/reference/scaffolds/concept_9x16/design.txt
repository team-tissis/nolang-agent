# 本文の書体 (`font`) と数字の書体 (`fonts n` = `font-family: n`) は style の組 (looks.md) で題材に合わせて決める — 下は骨組みの仮の値で、写さない。数字は太く字形のはっきりした物 (細いセリフ・等幅・筆の数字は細く見え、筆の「1」は「7」に見える)

# 役ごとの動き (題 title / 主役の語 big / 板 div / 本文 row / 注記 note)。変えたい役はこの行を書き換える。入場は書いた物だけ (書かなければ動かない) — 根の板には `in: div` を書く (def の板は書いてある・板の子は板と一緒に出る)
motion title { in: {y:-60, scale:0.94, opacity:0, duration:0.55, ease:'back.out(1.6)'}; out: {y:-24, opacity:0, duration:0.24} }

motion div { in: {y:36, opacity:0, duration:0.45, ease:'power3.out'}; out: fade {duration:0.22} }
motion row { in: {x:-90, opacity:0, duration:0.4, ease:'power2.out'}; out: fade {duration:0.2} }
motion note { in: {y:21, opacity:0, duration:0.35, ease:'power2.out'}; out: fade {duration:0.2} }
# 印の無い文字と一覧 (×N・群) は cut 頭に積まず、1 つ目は頭・2 つ目からは 2 文目以降に 1 つずつ出る (絵・板は頭のまま・cut ごとに `section#名(stagger: {each: .12})` で頭の組み上がりに戻せる)
# 一覧を頭に全部見せて強調を文で動かすなら `section#名(stagger: sentence,dim)` (2 つ目からは薄く出て、その文の頭で濃くなる)

# 主役の数字 (count はこの段で): 題 l + 数字 v (書体 n) + 単位 u。`v: "[count:150]"` は出ると同時に数える (3 桁以上・小数)

# 札は飾りの 2 語まで (判子・タグ)。要の語 (数字・比べる 2 つ・結論) は stat / big の段に

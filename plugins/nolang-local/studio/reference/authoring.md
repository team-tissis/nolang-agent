# 文法 (timeline.txt + design.txt) — draft src v2

正本は `docs/draft_src_v2/grammar-spec.md` (規則) と `grammar-spec-types.md` (型ごとの全 key・preset・やり方・形の名)。この辞書は著者向けの写し。型は raw の要素 (文字・箱・絵・icon・図形・幕・群) だけで、札の行・横棒・流れ図は根の `def` + `×N` で書く (下の「根の雛形」)。runtime の field ごとの書き方と書けない物は `capabilities.md`。
`src/` = `timeline.txt` (台詞・音・印 = いつ) + `design.txt` (要素・既定・palette = なに) + `src.json` (出力の設定・素材の pin)。両 file の 1 行目は `#v2` ちょうど (DEFECT:VERSION)。
短く書く順: 2 回以上書く物は根に 1 回 (`palette` `default` `def` `cast` `transition =`) → section はその場面の差分だけ。

## HTML 形 (著者が書く綴り)

design の要素は `tag#id.class(css 宣言) 内容` で書く (= HTML / CSS / GSAP の圧縮形。閉じタグは字下げ・style は要素の行・gsap.from は `in:{…}`・秒は台詞の語)。宣言は CSS の名と単位だけで書く (`[型 名] key=値` の行は DEFECT:BRACKET・括弧の中の `key=値` と、CSS の名を持つ宣言の短い名 `w:` `fill:` `size:` … は DEFECT:KEY)。
位置と寸法 `left top width height` (px・`x y` は GSAP の移動量だけ)・`background`・`border: 4px solid $a`・`border-radius`・`box-shadow: 0 6px 18px #0003`・`padding`・`font-size`・`font-family`・`font-style: italic`・`letter-spacing: .2em`・`line-height`・`text-align`・`vertical-align`・`text-shadow: 0 6px 4px #0008`・`writing-mode: vertical-rl`・`white-space: nowrap`・
`transform: rotate(-5deg) scale(1.1) skewX(-10deg) rotateX(30deg)` (`translate(x, y)` は位置に畳む: px は left / top に足す・`-50%` は cx / cy)・`transform-origin`・`opacity`・`filter: saturate(.3) sepia(1) blur(6px)`・`mix-blend-mode`・`clip-path: inset(8% 0 78% 0)`・`mask-image: linear-gradient(…)`・`object-fit` / `object-position`・`z-index`・`inset: 0` (全面)。
並べるのは `display: flex; gap: 36px` (`flex-direction: column` で縦・`flex: 1` = 残りを取る子・`align-items` / `justify-content` = 子の寄せ `center\|flex-end\|space-between\|space-around\|space-evenly`)。`div` の `padding` は書かなければ 0 (CSS と同じ)。CSS に名の無い NoLang の宣言 (`stroke` `tone` `scrim` `subject` `overlap` `exclusive` …) も `key: 値` で書く (下の表)。
動きは GSAP の object: `in:{y:45, opacity:0, duration:.5, ease:'power3.out', stagger:{each:.12, from:'end'}}` (stagger は tween の object の中だけ — 1 つの文字なら 1 字ずつ・×N と群なら instance の間隔)・印は `[!#id to,{scale:1.1, duration:.4, yoyo:true}]`。duration を書かない object (`in: {y: 45, opacity: 0}`・`rise {y: 30}`・`to,{scale: 1.1}`) は GSAP と同じ 0.5 秒・語だけの preset (`in: fade`) は語ごとの既定 (下の preset の表)。
`section#名(宣言)` = cut の見出し・`#名.tag(宣言)` = 変種・`@#名` = 再掲・`def 名(引数) = tag(宣言) 内容` = class・`img { main: kb {scale: [1, 1.06]} }` = 型の既定。

- 字幕: `subtitle.hug(font-size: 42px; bottom: 36px)` (根に 1 つ)。`.hug` = 寸法を書かない軸の帯を句ごとの文字の実寸に (`width` だけ書けば幅は固定・高さは句ごと、`width` `height` 両方なら固定の帯)。`left top bottom width height background border border-radius padding color font-family style telopbase` `in: pop; out: fade`・声の窓 `lead: 100; tail: 300; hold: next,800\|same\|off` (ms・lead / tail は 10000 まで — 窓は札の区間 = 次の札の頭か cut の終わりで切れるので、cut の最後の札を cut の終わりまで残すなら `tail: 10000`・hold の字幕札が cut 境界を跨ぐ時は engine が次の cut の lane と 1 枚に繋ぐ (帯は cut で入り直さない))・`wrap: comma,16; strip: 、。\|all\|、。>space; unit: phrase\|sentence; min_phrase: 0; label: edge\|above\|top_left\|inside; label_in: pop`。変種 `subtitle.x(transform: rotate(-3deg); ghost: #00E5FF,#FF2BD6,17)` (`main:` `lead:` `tail:` `hold:` も) + timeline の `[card:x]` (その札 1 枚)。

### 印 — 4 動詞
形: `[動詞#名[{tok}] [やり方[,引数…]] [±N | cut-N]`。名は design の要素の `#id` (派生名も・`#` が無いと DEFECT:NAME)。引数の無い `[>#名]` が最短。 印だけの行 (`[!#bar .s2]` を行頭に) = 次の台詞行の頭の印 (素の出す印だけの行 `[>#名 [+N]]` は出す行 = 旧 `show`) (文字や注釈は書けない)。後に台詞行が無い (cut 末の) 印だけの行は cut 末の拍: `[<#名 -N]` = `[<#名 cut-N]` (`+N`・出す・変える印と音は DEFECT:ARG)。

### 時刻の規則 (覚えるのは 4 つ・残りは check が言う)
1. 印はその語の頭で効く。ずらすのは `+N` / `-N` (ms) と `>` (同じ語の直前の印の終わりから) だけ (design の `delay:` は印の語からの遅れで、印に `+N` を書けばそれが勝つ)。札 (stamp) も同じ (文末に出すなら文末の語に書く)。状態の印 (`.tag` `to` `fill` …) の `-N` は変種の `move:` の lead 込みで 1000 ms まで (超えると DEFECT:BEAT_TOO_EARLY・前の語に打つか lead を縮める)。
2. 同じ語に並べた印は**同時** (暗黙の連鎖は無い)。cue の印も同じ。
3. cut の外へは出ない: `-N` は cut の頭より前へ出られず (頭の `[silence:N]` か根の `silence head=` の無音の中は可)、`+N` が末尾を越えた分は描かれない (warn:BEAT_AFTER_CUT・GSAP の clip と同じ)。退場は cut 境界で終わる (退場を次の cut の入りに重ねるのは cut 末の `transition none,N`・旧場面ごと残すのは `overlap=`)。
4. 尺は合わせない: 動画の尺は台本で決まる。依頼の長さ・`target_s`・章の時刻は目安で、寄せるために話速・無音・台詞を変えない (TTS は合成のたびに揺れる)。演出の無音 (溜め・声の無い場面・締めの余韻) は書く: 声の無い cut は `@名: [>#名 +N][silence:4s]` (cut 頭から N ms)・溜めは `[silence:0.8s][>#札]`・余韻は `[silence:1.0s][>#名][silence:2.0s]`。

書かなければこうなる (既定): cut 頭の印の無い要素は文書順に section の `stagger:` (120 ms) で組み上がる (`in: none` は数えない)・文字の下の細い横線 (`path: line_h` 高さ ≤ 12・印なし) はすぐ上の文字が `[>#名]` で出るならその語で一緒に出る (線だけが先に走らない)・印の無い板 (子を持つ箱か div) は中身 (子・`overlap:` で乗る要素・箱に 6 割以上入る後に書いた根の要素) が全部 `[>#…]` で出るなら最初の中身の語で一緒に出る (空の板が先に出ない — 枠を先に見せるなら `[>#板]` を中身の最初の値の 1 秒以内の語に・印の無い子 (見出しの小札も) が 1 つでもあれば板ごと cut の頭に出る — 中身が 1 秒以上遅れれば check の `empty_board`)・`stagger: sentence` (雛形の根 `cut { stagger: sentence }`) なら印の無い文字と一覧 (×N・群) を頭に積まず、文書順の 1 つ目 (印の無い題 `h1` / `chap` があれば題と、その前の kick・番号の札まで) は cut 頭・残りは 2 文目以降の頭に 1 つずつ `[>#名]` で出る (単位は名 / 群 / `名[k]`・文より多い分は最後の文に 120 ms ずつ・絵・箱・図形と `in: none` / `delay:` を書いた物は頭・自分で印 (どの動詞でも) を書いた物は頭のまま・足した印は保存の timeline に残る・`stagger: sentence,dim` は同じ単位を頭に全部出し 2 つ目からを入場から薄く置いて、その文の頭の `[=#名]` で戻す)・最後の cut の末尾は書かなければ `[silence:3s]` (書けばその値・`[silence:0]` も — BGM の既定の余韻 (持ち上げと末尾の fade) はこの無音の中に収まる)・`[>#名[*] +300]` は 300 ms 後に全部で間隔は印の `{stagger:{each:…, from:…}}` か design の入場の `in: {stagger: …}`・`[>#群 +300]` も同じ・子は親と同じ時刻と px で動き `[>#子]` の印があればその時・cut の t=0 は切替の窓の始まり (check が `窓 N ms` と書く)・状態 (`!` の変種) は `=` か要素が閉じるまで続き、sticky の要素は cut を跨いでも続く・cut 末尾の印 (`…ます。[>#札]`) は最後の語の頭 (後ろに置くなら `[silence:N]` を足して `+N`)・同じ拍の 1 状態 + 1 効果 / 2 効果は 1 つに畳む・絵文字つきの見出しはそのまま出る (TTS は読まない)・出した語と同じ拍の補間 `[>#a][!#a to,…]` と `{tok}` の印 `[>#a][!#a{t} strike]` は出現の 1 frame 後に送る (出た見た目を変えるなら `[>#a .tag]`)。
check が止める物 (黙って直さない): 出ていない要素への `!` `=` = DEFECT:NOT_OPEN・`>` は要素ごとに 1 回。同じ語で同じ要素を拍を書き分けて移す印は拍ごとに続き (逆順の拍でも後の拍の状態が勝つ)、文字全体の変化と `{tok}` の印も同じ語に並べてよい。

### cue と切替
- cue: `cue 名(引数[=#既定], …) = [印][印]…` (design の根)。本体は印だけ。引数は印の名の位置 (`x`) か派生 (`x.c`・`x[2]`)、やり方の中の `{引数}` は値 (数も)。`prev` = 同じ cut で前に呼んだ時の最初の引数 (最初の呼び出しでは `prev` の印を落とす)。呼び出し `[名 値 値 [±N]]` (空白区切り・既定値のある引数は省ける・末尾の `+N` / `-N` は展開した印の全部に足す)・印は並べた印と同じ = 同時。例: `cue on(x) = [=#prev][!#x tint,$a][!#x.c fill,$a]` → `[on org.l[2]]`・`cue slam(x, s=2.4) = [>#x pop][!#x punch,300,{s} +300]` → `[slam v 1.3]`。
- 切替: `transition 種,ms[,key=値…]` (cut の末尾)・根の `transition = …` が既定。ms は 100〜3000。`overlap=N` = 窓のうち境界の後ろの長さ (既定 0 = 窓は境界の前)。窓が最後の声に掛かると check が warn (`transition_over_speech`)。幕の切替 (`dip` `flash` `panel`) は最後の cut と根の既定に書けない (DEFECT:TRANSITION_PLACE)。`se=音 [token…]` = 境目 (次の cut の頭) で鳴らす音 (`cut` 以外のどの種にも)。`.sticky` / `z-index: front` の要素は切替の上に残る (次の cut の頭で閉じる帯も)。`transition cut` (ms 無し) = その cut だけ切替なし (根の既定を打ち消す)。`transition panel,1000,color=$色,label="01 原因"[,skew=-12][,label_skew=0][,dir=right]` = 斜めの色の帯が覆い、帯の裏で場面が替わる (章の名は既定で帯と同じに傾く・`label_skew=0` で立てる・大小は label の中の run `{sm}01{/} 原因`・章の帯・最後の cut と根の既定には書けない・label を読ませるので 1000 以上 — 短いと warn:flash_text)。幕 (dip / flash / panel) に `overlap=` `ease=` は書けない。
- `none,N` = 混ぜない: 次の cut は、この cut の退場が終わる N ms 前に始まる (旧場面を新場面の上にそのまま描く — 退場 (`out:`・section の `out:`・自動の閉じ) は境界 + N で終わる・N だけで key は無い・根の既定にも書ける)。`dissolve,ms[,overlap=][,zoom=][,ease=][,color=#色]` = 溶ける (linear が既定・`color=` = 旧場面を描かず色の上から出る — 400 ms を超えると暗転に見えて warn:DARK_DIP・`dissolve,300,overlap=300` = 窓が境界の後ろ — 前の cut の退場が済んでから溶ける)。`push,ms,dir=left|right|up|down[,overlap=][,ease=]` = 新場面が旧場面を押し出す (cut を跨ぐ sticky の地・帯と字幕は止まったまま)。`slide,ms,dir=[,offset=38%][,opacity=0][,drift=px][,dim=0.38]` = 新場面が滑り込む (旧場面は `drift=` だけ同じ向きへずれ、`dim=` まで暗く沈む — 頁替え)。`dissolve,…,dir=right,bars=…` = 溶けの上を帯が払う (帯は溶けと独立)。
- `wipe,ms,dir=[,bars=#色,18;#色,8][,drift=px][,angle=deg][,overlap=]` = 縁が走る (帯は 4 本まで・1 本目が新場面側・`linear(…)` 可・`linear(…,180)` = 帯の箱の CSS の向き (縦のグラデ))。`zoom,ms,dir=in|out[,zoom=1.08]` = 寄って / 引いて替わる。`dip,ms[,color=#000000][,level=1]` = 幕を挟む (前半で濃く後半で薄れ)。`flash,ms[,color=#FFFFFF][,level=1]` = 閃光 (ms/3 で光り残りで引く) — 峰の 1〜2 frame は画面が色だけになる (見比べでは白 frame の欠陥に数えられる)。cut の切替には使わず、閃光は全面の `veil#名` を語で出して `to,opacity=0` で引く。例: `wipe,700,dir=left,bars=#E8743B,18`・`dip,400,color=#FFFFFF,level=0.6`。

## 欠陥 — 効くか欠陥か
書いた物が効かない状況は全部欠陥。黙って捨てる・割る・丸める・詰めるは無い。

| 状況 | 結果 |
|---|---|
| ×N に枠 1 つで `display` 無し | 横に並べる (縦長の枠は縦)。×N の行の `width height` は枠全体 (N 等分して 40 px 未満なら DEFECT — 1 枚の寸法なら N 枚 + gap を書く) |
| 退場の `-N` が cut の頭より前・前の印と交差 | DEFECT:BEAT_BEFORE_CUT / BEAT_OVERLAP (直前の語まで詰めない) |
| `section#名(out: fade {duration: .04})`・`[<#名 cut-0]` + `out:` | 書いた ms どおり描く・境界で終わる |
| 出した語の後の子の punch・def の `out:`・`[count:… delay= ease=]`・`[card:x]` の `lead tail hold`・文字全体の `recolor` | 効く (子に継ぐ・補間する) |
| `to` の後の `.tag`・`pattern:` だけの箱・群の clip の箱の border | 重なる (位置は戻らない)・地は透明 (既定の白地は無い)・clip の窓は border の外周 |
| run の class が無い `{t}…{/}` | 印の的だけ (可)。`{hl}` が class でも的でもなければ DEFECT:RUN_UNKNOWN |
| 同じ語の印・cue の印・`+N` | 同時 (規則 2)。`+N` は ×N でも群でも遅れだけ (規則 3)。札の文末着地 (`now`) は無い (規則 1) |
| runtime の値域・大文字の名 | compile が検査し DEFECT:RANGE に下限・上限を書く (`Input should be ≥ 0` は出ない)・DEFECT:NAME (読み替えない) |

報告の形 `DEFECT:コード  file:行 [section か *** cut]  原因。直し方: …` (1 行 1 件・著者の語彙で)。欠陥の section は捨てて compile を続け、その名を指す印・参照は巻き添えの欠陥に数えない。似た名・似た key があれば `似た名: a, b`。段: DEFECT (描けない・compile が止める) / severe (描けるが崩れる = `overflow occluded offcanvas`) / warn (engine が書いた値を変えた・判定で損 = `overridden shrunk transition_over_speech`) / info (参考 = `SAME_AS_DEFAULT Z_CHILD substituted long_still`)。直すかは段でなく規則の台帳の直しの列・`lint off=` は台帳の mutable の規則の warn / info を黙らせる。コード: `VERSION TAB INDENT NAME TAG UNIT COLOR QUOTE ARG KEY KEY_DUP REF ROOT_AFTER_CUT DUP_NAME DUP_CUT CUT_UNKNOWN CHILD_UNKNOWN CHILD_TYPE NAME_SHADOW TIMES_N_FRAME FOLD TRANSITION_PLACE FADE_MARK BEAT_BEFORE_CUT BEAT_AFTER_CUT BEAT_OVERLAP NOT_OPEN RANGE SVG_VIEWBOX ASSET_AMBIGUOUS RUN_UNKNOWN ICON_UNKNOWN SHAPE_UNKNOWN EASE_UNKNOWN CAST_KIND CSS`・check の配置の崩れ severe `overflow occluded` (engine が解けなかった収まり — 描けるが崩れる)。決定性: 素材 id・font の pin は `src.json` (`asset_pins`)。曖昧な説明文は check が解いて pin に書く。pin に無い素材を説明文で書いた src は決定的でない。

書き間違えやすい物 (check が DEFECT にし、直しの 1 往復 10〜15 s が乗る — 担当の版で多い順):
- 効果 (`punch` `shake` `pulse` …) の key は duration= rotation= pivot= scale= だけ。`stagger` は出現 (`[>#c[*] {stagger:{each:0.08}}]`) と入場の tween の中にだけある
- `to` の key は x= y= (base からの px) left= top= cx= cy= (行き先) width= height= (大きさ) scale= (倍率) rotation= opacity= … — object では `{width: 300}`・数の tween `to,{textContent: 1231, snap: {textContent: 1}}` は数え直し (`text,"[count:1231]"`)・GSAP の `keyframes` は無い (`keys(…)`)。`in:` / `out:` の tween に幅の channel は無い (伸びは `scaleX` + `pivot: 'left'`)
- `flip:` は名前の icon と写真・絵・svg だけ (文字・箱には無い)
- 塗りを焼く箱 (`background:` のある div) は width と height の両方が要る (`def` の `p` を div に替えた時に抜けやすい)
- 字下げした行は親 (div / group) の子だけ。親の無い要素の行は字下げしない
- 随伴 (`overlap: 親` で親に乗る札・判子) は親を動かす語より前の語で出す。同じ語で出して動かすと DEFECT

## HTML の動画を写すとき (HTML + GSAP の動画を NoLang で)
- 切替: 古い場面が境目で消え新しい場面だけが黒の上で opacity 0→1・scale 1.08→1 → `transition = dissolve,320,color=#000000,zoom=1.08,ease=power2.out` (根の既定にも)・新しい場面が不透明な旧場面の上に重なる → `dissolve,600,overlap=600`・黒 / 白の挟み → `dip,400` / `dip,600,color=#FFFFFF`・横に払う色帯 → `wipe,700,dir=left,bars=#E8743B,18` (境界から払うなら `overlap=700`)・斜めの光の帯 → `wipe,340,dir=right,overlap=170,angle=14,bars=linear(#00E5FF00,#00E5FF@30%,#FFFFFF,#FF2BD6@70%,#FF2BD600),470`・cross fade の上を光の帯が払う → `dissolve,850,overlap=850,dir=right,bars=linear(#F5B54400,#FFD27F8C@97%,#FFD27F00),173`・払う線の上下のグラデ → `wipe,600,dir=right,bars=linear(#7ADFD300,#7ADFD3F2@30%,#F6C35BF2@70%,#F6C35B00,180),3`・頁替え (旧頁が `x:-360` へずれて暗む) → `slide,850,dir=left,drift=240,dim=0.38`・`clip-path: circle(0% at 50% 0%)` から開く → `in: circle_wipe {duration: .75, ease: 'power2.inOut', pivot: 'top'}` (円の中心は pivot の 9 名)・`xPercent:38,opacity:0` で被さる → `slide,260,dir=left,offset=38%,opacity=0,ease=expo.out`・場面の要素が一斉に去る leave() → `section#名(out: {x: -39, opacity: 0, duration: .4})`・旧場面の一部だけ流す → その要素に `out: {x: -210, ease: 'power1.inOut', duration: .7}` + `[<#box cut-0]`・旧い板が抜ける間に新しい板が入る (`tl.to(old,{y:-42,opacity:0,duration:.42}, t)` の直後に新しい場面) → `transition = none,370`・黒から入る → `fade in,1800`。切替の窓には次の cut の頭の層が描かれ入場も窓の頭から走る — 帯が過ぎてから入れるなら `delay:` に尺。
- 時刻: 声の尺は元の動画と違ってよい (`[silence:]` で合わせない)。要素・切替・字幕は**台詞の同じ語**に合わせる (元の動画でその語の何秒後に出るかを見て `+N`)。配列の同時の tween (`tl.to([a, b], …)`) = 同じ語に並べるだけ (同時)・順に続くなら `+130` `+260`。
- 素材: 声・BGM・効果音・書体は元の動画と同じ素材を `id=8桁` か表示名で固定・同じ人物は根の `image 名 = "…"` + 内容 `[ref:@名]場面`・同じ写真の差分は `[ref:@名]消す物 / Edit only the sky to dusk`。絵の中身・構図は作り直してよい — 一貫性 (`[ref:@名]`) と文脈 (台詞の被写体が写る) を保ち、絵に重ねる輪・矢印は新しい絵に合わせて置く (render の frame で確かめる)。
- 入場: GSAP の px (`y: -44`) → `in: {y: -66, opacity: 0, duration: .6}`・keyframe 列 (`fromTo({x: 662})` + 行き過ぎ) → `in: keys(at=0 x=441 opacity=0 | at=0.7 x=-8 ease=power2.out | at=1 ease=sine.inOut),duration=900` (子は同じ px で一緒に動く)・`scaleX: 0` の罫 → `in: wipe {dir: 'center'}`・文字を 1 字ずつ → `in: rise {y: 30, duration: .4, stagger: .04}`・`stagger: {from: "random"}` → `[<#名[*] from=random]`・CSS の `border` は箱の外に足すが NoLang の `border:` は箱の内側に描く (CSS と同じ外寸なら width / height に線幅 × 2 を足す)。
- 動き: 1 文の中で続ける tween (`-15° → -30° → -22°`) → 静止 `transform: rotate(-15deg)` + 1 語に拍を書き分けた `to` (`[!#a to,rotation=-30,duration=600 -50][!#a to,rotation=-22,duration=550 +750]`・GSAP と同じ絶対値・相対は `rotation+=8`)・揺れ (`rotation:4, x:30, .18s, yoyo, repeat:3`) → `[!#a to,rotation=4,x=20,duration=180,repeat=3,yoyo]` か `[!#a wiggle,4,duration=180,count=2,x=20]`・広がる波紋 (輪 0.3→1.6) → `[!#a ping,scale=0.3>1.6]`・語から始まる浮遊や流れ → `[!#a main,sine,y=-7,freq_ms=1100,window=0,3300]`・`motionPath` / 弧の入れ替え → `[!#a to,x=760,arc=0.4][!#b to,x=160,arc=0.4]`・scale と位置の Ken Burns → `main: kb {scale: [1.04, 1.17], focus: ['55% 48%', '45% 50%']}`・`attr: {points}` の tween → `#s.ex(points: "…")` + `[!#s .ex]`・2〜4 重の波紋 → `[!#名 ping,3,interval=280]`・白い閃光 → 全面の `veil#fl(color: #FFFFFF; opacity: .55; z-index: curtain; in: none)` + `[>#fl][!#fl to,opacity=0,duration=400]`・画面の揺れ → 出ている要素ごとの `[!#名 shake,6,duration=2200]` を同じ語に・odometer → `[count:400 roll ms=1150,1000,850]` (回らない上位の桁は `ms=0,0,1380,1460`)・`background-position` で走る光 → `group#g(sheen: g.bg,900,soft,sine.inOut)`・`perspective: 780px` + `rotateX(70deg)` の床 → 群に `main: constant {rotationX: 70, depth: 4, pivot: 'top'}`・公転 → `group#orb(main: spin {period: 9, pivot: 'orb.sun'})`・奥へ回り込む公転 (GSAP の zIndex の切替) → 同じ軌道の写しを相手の下に置き、square の alpha で半周ずつ見せる (`[!#orb.oy.earth main,square,alpha=1,freq_ms=T,phase_offset=p]` / 奥の写しは `alpha=-1`・p は y の sine と同じ)。
- 文字の一部: `余裕` だけ 1.12 倍 → 内容 `…{t}余裕{/}…` + `[!#名{t} punch,1.12,duration=440]`・色の tween (0.25 s → 戻り 0.4 s) → `[!#名{t} recolor,$o,duration=250,back=400]` … `[=#名{t} +600]`・語の下帯 (`linear-gradient(transparent 62%, 色 62%)`) → `run m { marker: $y,38% }` + `[!#名{m} marker]` (帯は文字の直下の段で行の箱 (line-height) の下から比だけ・字の下へはみ出す。字幕では run の地で同じ形 (印の拍では伸びず札と一緒に出る))・拡大したまま保つ → 別の文字に分けて `p#t2(left: t1.right; top: t1.top; overlap: t1)` + `[!#t2 to,scale=1.08]`。
- 配置: `display:flex` の行と列はそのまま書ける — 横は文字幅のまま並び `flex: 1` の子が残りを取る (icon + 文字の行)・縦は子の実の高さ + `gap` で積む・`align-items` / `justify-content` の center / flex-end / space-between / space-around / space-evenly は子の寄せ・`margin: 0 auto` は left と right が同じ値の時だけ中央 (`cx: 50%`)・`margin-left: auto` は書かず `right:`。
- 見た目: `transform: skewX(-12deg)` はそのまま (語で `[!#名 to,skewX=12]`)・`rotateX` の立体 → `transform: rotateX(30deg); depth: 0.8` (下辺を軸に `main: constant {rotationX: 30, depth: 0.8, pivot: 'bottom'}`)・`scaleX: -1` → `flip: x`・`box-shadow: 0 0 0 21px #色` はそのまま・`filter: saturate() sepia()` はそのまま / 語で `[!#名 filter,duration=600,sat:0]`・全面の `mix-blend-mode: saturation` → `veil#g(filter: saturate(0); z-index: front)` を `[>#g]` … `[<#g]`・`background-clip: text` の金文字 → `color: linear(#FFE58A,#C2410C,180)` (文字の色は `linear(…)` の形だけ)・`background: linear-gradient(… 42%, … 72%)` はそのまま・`repeating-linear-gradient(100deg, …)` → `pattern: hatch,10,…` (CSS の勾配の向きと 90° ずれる)・`mask-image` + 単色 → `look: #色`・duotone → `look: #暗/#明`・写真の上の光 → `div#lk(inset: 0; background: radial(#FFE6A0,#00000000,70%,25%); mix-blend-mode: screen)`・写真の暗幕 → `img#p(…; scrim: right,0.45)`・`transformOrigin` → `transform-origin:`・`steps(1)` → `ease: 'steps(1)'`・左右 2 色の札 → `p#b(left: a.right; top: a.top; border-radius: 0 148px 148px 0; overlap: a)`・両脇の線 → `rules: both,54,3,$a`。
- 字幕: 元の動画の句の割り方 → `[|]` (札だけ切る)・`[||]` (文を跨いで 1 枚)・`subtitle "…"` の上書き・`subtitle(min_phrase: 0)`。句ごとに傾き・入り方・色ずれが違う字幕 → `subtitle.変種(…)` を句の数だけ + 札の頭に `[card:変種]`・切替の前に字幕だけ先に消す → `subtitle.early(tail: 0; hold: off)` + `[card:early]`。
- 場面の組み立て: 「空にしてから組み立てる」 → 切替を書かない + 前の cut に `section#名(out: …)` + 次の cut の要素に `delay:`。場面の頭の札 (章・STEP) には印を付けず cut 頭に (`section#名(stagger: 0)` で一斉)。通しの章の札 (sticky の帯) を cut ごとに置き直さない — 根に 1 つ + 変種 `[!#bar .s2]` か文字の差し替え `[!#bar.t text,"2 / 5"]` で段を替える (章・STEP・累計の常設は 3 分以上の動画だけ・上端に・飾りの header は置かない)。元の動画に無い効果 (閃光・弾む入場) を足さず、小さな飾り (カーソルの名札・点・鳥) も省かない (`group` + `to`・`path: scatter,n=800,seed=3`・`ping,n`)。camera の寄る cut で `cam: none` の見出しより上に幕を出すなら幕に `cam: none; z-index: curtain`。

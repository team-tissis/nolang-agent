# Grammar (timeline.txt + design.txt) — draft src v2

The source of truth is `docs/draft_src_v2/grammar-spec.md` (rules) and `grammar-spec-types.md` (every key, preset, technique and shape name per type). This dictionary is the copy for authors. Types cover raw elements only (text, boxes, pictures, icons, shapes, veils, groups) — card rows, horizontal bars and flow diagrams are written with a root `def` + `×N` ("root templates" below). How each runtime field is written, and what cannot be written, is in `capabilities.md`.
`src/` = `timeline.txt` (speech, sound, marks = the when) + `design.txt` (elements, defaults, palette = the what) + `src.json` (output settings, asset pins). Line 1 of both files is exactly `#v2` (DEFECT:VERSION).
Write short, in this order: anything written twice or more goes into the root once (`palette`, a type rule `tag { }`, `def` `cast` `transition =`) → each section then holds only that scene's differences.

## HTML form (the spelling authors write)

A design element is written `tag#id.class(css declarations) content` (= compressed HTML / CSS / GSAP: closing tags become indentation, style lives on the element's line, gsap.from is `in:{…}`, seconds come from the spoken words). Declarations use CSS names and units only (a `[型 名] key=値` line is DEFECT:BRACKET; `key=値` inside the parentheses, and short names for declarations that have a CSS name — `w:` `fill:` `size:` … — are DEFECT:KEY). Declarations (def-instance arguments too) are separated by `;` only — a JS-style `,` between them is DEFECT:KEY; inside a GSAP object the separator is `,` only — `;` there is DEFECT:ARG.
Position and size `left top width height` (px; `x y` are GSAP movement amounts only), `background`, `border: 4px solid $a`, `border-radius`, `box-shadow: 0 6px 18px #0003`, `padding`, `font-size`, `font-family`, `font-style: italic`, `letter-spacing: .2em`, `line-height`, `text-align`, `vertical-align`, `text-shadow: 0 6px 4px #0008`, `writing-mode: vertical-rl`, `white-space: nowrap`,
`transform: rotate(-5deg) scale(1.1) skewX(-10deg)` (the functions compose in written CSS order and draw while the layout position and size are kept — `translate()` px, and a translate after a rotation, stay in the matrix; `%` is measured against the element's own box (for text and %-boxes whose size is not fixed, only a leading `translate(-50%, -50%)` right after `left` / `top` is read as centering, anything else is DEFECT); 3D functions such as `rotateX()` are DEFECT — a static tilt is `rotationX: 30; depth: 0.8`; `transform-origin` and a static `scale()` resolve against the written `left top width height` box (a group with no written box uses the center of its members' union; the union, like the engine, reaches the outer edge of member strokes = a thick-stroke path / line is wider by its stroke width); a rotation with an origin (including a full turn `to,{rotation: 360}`) keeps the origin in its state key and turns around it as written; `transform: none` is the identity (a variant cancelling the base rotation; also as an item of an ×N list `"rotate(-6deg);none;none"`)), `transform-origin`, `opacity`, `filter: sepia(1) saturate(.3) blur(6px) drop-shadow(0 8px 16px #0008)` (drop-shadow is the same engine shadow as box-shadow — text, shapes, pictures, svg and icons only; a box with children is DEFECT. The engine applies the color matrix (sepia / grayscale / invert) first — write the matrix first so it matches the written CSS order; color grading (sepia / saturate / brightness / contrast / look) does not apply to text, so a color-grading filter on text is DEFECT — text color is `color:`), `mix-blend-mode`, `clip-path: inset(8% 0 78% 0)`, `overflow: hidden` (clips a box's children inside its edge, with its corner radius), `mask-image: linear-gradient(…)`, `object-fit` / `object-position`, `z-index`, `inset: 0` (full-bleed), `inset: 40px 60px` (four sides).
Arranging is `display: flex; gap: 36px` (`flex-direction: column` for vertical; `row-gap` / `column-gap` work as in CSS only along the main axis (horizontal uses column-gap); `flex` is as in CSS (`flex: 1` = `1 1 0%` splits the remainder evenly; `flex-grow` / `flex-shrink: 0` / `flex-basis: 200px` too; unwritten means `0 1 auto` = content size); `align-items` / `justify-content` = child alignment `flex-start\|center\|flex-end\|baseline\|space-between\|space-around\|space-evenly` — an unwritten `align-items` is stretch, as in CSS), or the normal flow of a `div` without display (children without positions stack vertically; `margin` opens gaps). A `div`'s `padding` is 0 unless written (as in CSS). NoLang declarations with no CSS name (`tone` `scrim` `subject` `overlap` `exclusive` …) are also written `key: 値` (table below).
Motion is a GSAP object: `in:{y:45, opacity:0, duration:.5, ease:'power3.out', stagger:{each:.12, from:'end'}}` (stagger lives only inside the tween object — on a single text it staggers per glyph, on ×N and groups per instance); a mark is `[!#id to,{scale:1.1, duration:.4, yoyo:true}]`. An object without duration (`in: {y: 45, opacity: 0}`, `rise {y: 30}`, `to,{scale: 1.1}`) is 0.5 s, as in GSAP; a word-only preset (`in: fade`) takes that word's default (preset table below).
`section#名(宣言)` = a cut's heading; `#名.tag(宣言)` = a variant; `@#名` = a re-mention; `def 名(引数) = tag(宣言) 内容` = a class; `img { main: kb {scale: [1, 1.06]} }` = a type default.

### Marks — four verbs
Form: `[動詞#名[{tok}] [やり方 [{object}]] [+300ms | -300ms | cut-400ms]`. The name is a design element's `#id` (derived names too; missing `#` is DEFECT:NAME). The bare `[>#名]` is the shortest. Target arrays `[!#a,#b,#c to,{…}]` / `[>#a,#b]` / `[<#a,#b +300ms]` (GSAP's `tl.to([a, b, c], …)`; no space after `,`; `#` per target) = the same mark per target (one beat; `stagger: {each, from}` is the interval and order along the target list; a missing target is DEFECT:NAME; subtitles cannot be listed). A mark-only line (`[!#bar .s2]` at line head) = a mark on the head of the next speech line (a bare show-mark-only line `[>#名 [+300ms]]` is a show line = the old `show`) (no text or annotations allowed). A mark-only line with no speech line after it (at the cut's tail) is the tail beat: `[<#名 -400ms]` = `[<#名 cut-400ms]` (`+300ms`, show marks, change marks and sounds are DEFECT:ARG).

### Timing rules (memorize four — check tells the rest)
1. A mark takes effect at its word's head. Shifting is only `+300ms` / `-.3s` (a time with its unit) and `>` (from the end of the previous mark on the same word) (design's `delay:` is a delay from the mark's word; a `+300ms` on the mark wins). Cards (stamps) are the same (to show at a sentence's end, write it on the last word). For state marks (`.tag` `to` `fill` …), a negative beat is capped at 1000 ms including the variant's `move:` lead (beyond is DEFECT:BEAT_TOO_EARLY — mark an earlier word or shorten the lead).
2. Marks listed on the same word are **simultaneous** (no implicit chain). Cue marks too.
3. Nothing leaves the cut: `-300ms` cannot go before the cut's head (inside the head `[silence:600ms]` or the root `silence head=` silence is fine), and whatever `+300ms` pushes past the tail is not drawn (warn:BEAT_AFTER_CUT; same as GSAP's clip). Exits finish at the cut boundary (overlapping an exit into the next cut's entrance is the cut-tail `transition none {duration: N}`; keeping the whole old scene is `overlap=`).
4. Never fit the length: the film's length is decided by the script. The requested length, `target_s` and chapter times are estimates — do not bend speech speed or silences to meet them, and no synthesize-and-remeasure round trips (TTS wobbles on every synthesis). Decide the amount of speech from the requested length before writing (1 second ≈ 6 characters at the cast's speed=100% — the speed scales it: speed=150% reads ≈ 9 characters a second; in stream the plan hands each cut a target). Pauses the piece needs are a different thing — the ban is only on bending them toward the length. Decide them up front with the speech, where a viewer needs a breath: a chapter card or title held with no narration (1.5–3 s), a beat after a question or before a reveal, a beat after a number that should sink in, the closing afterglow. A voiceless cut is `@名: [>#名 +800ms][silence:2s]` (800 ms from the cut head; `0 sentences` on a plan line); a held beat is `[silence:0.8s][>#札]`; afterglow is `[silence:1.0s][>#名][silence:2.0s]`. With a reference, copy where it pauses.

What happens unwritten (the defaults): entrances are only the written `in:` (elements with no `in:`, group members and box children appear in place at their time — no type has a default entrance); markless elements at a cut head assemble in document order, one entrance-owning unit at a time (a group is one unit), only in cuts that write a `stagger:` and in `stagger: sentence` cuts (120 ms) (`in: none` and unwritten in are not counted); a markless board (a section with indented children) appears on the first child's word when all its written children show via `[>#…]` (an empty board never leads — to show the frame first, put `[>#板]` on a word within 1 second of the first content; if even one child (a heading's small card too) is markless, the whole board shows at the cut head). Only structure (indented children) feeds this timing — elements riding the board via `overlap:` or by lying inside its box do not (moving the box never changes when it shows): a board left empty by late riders gets check's `empty_board`, and a thin line (`path: line_h`) running ahead of its heading gets check's `lone_line` — in both cases write the mark (`[>#板]` / `[>#線]`) on the content's word yourself (a source or footnote likewise: unmarked it sits at the cut head ahead of its chart — check's `note_first`; mark it on the chart's word); with `stagger: sentence` (the template root `cut { stagger: sentence }`) markless text and lists (×N, groups) are not piled at the head: the first in document order (with a markless title `h1` / `chap`, the title plus its preceding kick and number card) sits at the cut head, the rest come one per sentence head from the second sentence on with `[>#名]` (units are a name / group / `名[k]`; the overflow beyond the sentences lands on the last sentence 120 ms apart; pictures, boxes, shapes and anything with `in: none` / `delay:` stay at the head; anything that wrote its own mark (any verb) stays put; the added marks remain in the saved timeline; `stagger: sentence,dim` shows the same units all at the head, places the second one on dimmed from the entrance, and restores each on its sentence-head `[=#名]`); the last cut's tail, unwritten, is `[silence:3s]` (written values win, `[silence:0ms]` too — the BGM's default afterglow (the lift and the tail fade) fits inside this silence); `[>#名[*] +300ms]` = all of them 300 ms later, spaced by the mark's `{stagger:{each:…, from:…}}` or design's entrance `in: {stagger: …}` (`[>#群 +300ms]` likewise); children move at the parent's time and px, or at their own `[>#子]` mark's time if they have one; a cut's t=0 is the start of the transition window (check prints `窓 N ms`); a state (`!` to a variant) lasts until `=` or the element closes, and on a sticky element across cuts; a mark at the cut's tail (`…ます。[>#札]`) lands on the last word's head (to place it after, add `[silence:1s]` and use `+300ms`); one state + one effect, or two effects, on the same beat fold into one; two states on the same beat fold last-wins only when they write the same channel (`dim` and `to,{opacity}`), while different channels (`to,{opacity: 1, duration: .3}` and `to,{rotation: 720, duration: 3.6}`) run each with its own window and ease, like simultaneous GSAP tweens; ### Cues and transitions
- cue: `cue 名(引数[=#既定], …) = [印][印]…` (a design root). The body is marks only. Arguments sit where a mark's name goes (`x`) or a derivation (`x.c`, `x[2]`); `{引数}` inside a method is a value (numbers too — `to,{opacity: {o}, duration: {d}}`; the body is written like any mark, no exception). `prev` = the first argument of the previous call in the same cut (on the first call, marks on `prev` are dropped). A call is `[名 値 値 [+300ms]]` (space-separated; arguments with defaults may be omitted; a trailing `+300ms` / `-300ms` adds to every expanded mark — a unitless trailing number is an argument); the marks behave like listed marks = simultaneous. Examples: `cue on(x) = [=#prev][!#x tint,$a][!#x.c fill,$a]` → `[on org.l[2]]`; `cue slam(x, s=2.4) = [>#x pop][!#x punch {scale: {s}, duration: .3} +300ms]` → `[slam v 1.3]`.
- Transitions: `transition 種 {duration: 秒, key: 値…}` (at the cut's tail) — a word + one GSAP object like a mark (times are seconds; unwritten duration = 0.5; the old `種,ms,key=値` is DEFECT:ARG); the root `transition = …` is the default. duration is 0.1〜3. `overlap` = the part of the window after the boundary (default 0 = the window sits before the boundary). A window reaching the last voice gets check's warn (`transition_over_speech`). The band curtain (`panel`) cannot be written on the last cut or as the root default (DEFECT:TRANSITION_PLACE); `fade` (and its sugar `dip` / `flash`) may close the last cut (= `fade out`). Each transition gets its matching `切替音` automatically (sounds.md "Transition sounds"); `se=音 [token…]` replaces it (for any kind except `cut`) — with no beat the engine lines the sound's loudest moment up with the transition's peak (the window's middle for dissolve / wipe / push / slide; the moment the screen is fully covered for dip / flash / panel; the default swish does the same), so the whoosh hits with the move; a written beat (`+100ms`) places the sound's head from the next cut's head. `.sticky` / `z-index: front` elements stay above the transition (so does a band closing at the next cut's head). `transition cut` (no object) = no transition for that cut only (cancels the root default). `transition panel {duration: 1, color: '$色', label: "01 原因", skew: -12, label_skew: 0, dir: 'right'}` = a slanted color band covers the screen and the scene changes behind it (the chapter name tilts with the band by default; `label_skew: 0` uprights it; sizes via a run inside the label `{sm}01{/} 原因`; a chapter band — cannot be written on the last cut or as the root default; the band sweeps in 0.34 s and out 0.36 s and the rest of the duration holds the label — 0.8 holds it 0.1 s, so a label meant to be read wants ~1.2–1.5 (check's `transition_label_flash` names it)). Curtains (dip / flash / panel) take no `overlap` `ease`.
- `none {duration: N}` = no blending: the next cut starts N s before this cut's exits finish (the old scene draws as-is above the new — exits (`out:`, the section's `out:`, auto closes) finish at boundary + N; duration only, no other keys; can also be the root default). `dissolve {duration, overlap, zoom, ease, color: '#色'}` = a dissolve (linear by default; `color` = the old scene is not drawn, the new rises out of the color — over 0.4 s it reads as a blackout and warns DARK_DIP; `dissolve {duration: .3, overlap: .3}` = the window sits after the boundary — it melts after the previous cut's exits are done). `push {duration, dir: 'left|right|up|down', overlap, ease}` = the new scene pushes the old one out (sticky grounds and bands crossing cuts, and the subtitles, stay still). `slide {duration, dir, offset: '38%', opacity: 0, drift: px, dim: .38}` = the new scene slides in (the old shifts by `drift` the same way and sinks to `dim` — a page turn). `dissolve {…, dir: 'right', bars: '…'}` = bars sweep over the dissolve (the bars are independent of the melt).
- `wipe {duration, dir, bars: '#色,18;#色,8', drift: px, angle: deg, overlap}` = an edge sweeps (up to 4 bars; the first rides the new-scene side; `linear(…)` allowed; `linear(…,180)` = the CSS direction within the bar's box (a vertical gradient)). `zoom {duration, dir: 'in|out', zoom: 1.08}` = changes while pushing in / pulling back. `dip {duration, color: '#000000', level: 1}` = a curtain in between (darkens in the first half, thins in the second). `flash {duration, color: '#FFFFFF', level: 1}` = a flash (lights up over a third of the duration, recedes over the rest) — for 1〜2 frames at the peak the screen is pure color (side-by-side judges count it as a white-frame defect). Do not use it as a cut transition; a flash is a full-bleed `veil#名` shown on a word and pulled back with `to,{opacity:0}`. Examples: `wipe {duration: .7, dir: 'left', bars: '#E8743B,18'}`; `dip {duration: .4, color: '#FFFFFF', level: .6}`.

## Defects — it works or it is a defect
Any situation where what you wrote does not take effect is a defect. Nothing is silently dropped, split, rounded or squeezed.

| Situation | Result |
|---|---|
| ×N positions / sizes written as one value (every instance in the same box) | DEFECT:TIMES_N_FRAME (×N only copies; it does not split a frame). To lay them out, make the frame the parent box (`display: grid; grid-template-columns: repeat(3, 1fr)` / `display: flex; flex-direction: column` + children with `flex: 1`) and write no positions on the ×N children; to stack them, write positions per instance with `;` (`left: "240;240;240"`). An ×N whose descendant positions are written per instance (orbit of a group's copies) is not a defect. Indented children of a parent box do not inherit the type default's entrances/exits (`div { in: … }`) (children ride the parent) — to reveal items one by one, write `in:` / `out:` on the child ×N |
| An exit `-300ms` before the cut's head, or crossing an earlier mark | DEFECT:BEAT_BEFORE_CUT / BEAT_OVERLAP (it does not snap to the previous word) |
| `section#名(out: fade {duration: .04})`; `[<#名 cut-0ms]` + `out:` | Draws exactly the written ms; finishes on the boundary |
| A child's punch after the shown word; a def's `out:`; `[count:… delay= ease=]`; `lead tail hold` on `[card:x]`; a whole-text `recolor` | They take effect (inherited by children; interpolated) |
| A `.tag` after `to`; a box with only `pattern:`; the border of a group clip's box | They overlap (positions do not reset); the ground is transparent (there is no default white ground); the clip window is the border's outer edge |
| `{t}…{/}` with no run class | A mark target only (fine). If `{hl}` is neither a class nor a target, DEFECT:RUN_UNKNOWN |
| Marks on the same word, cue marks, `+300ms` | Simultaneous (rule 2). `+300ms` is only a delay, for ×N and groups too (rule 3). There is no sentence-end landing for cards (`now`) (rule 1) |
| Runtime ranges; uppercase names | compile checks and writes the bounds into DEFECT:RANGE (`Input should be ≥ 0` never appears); DEFECT:NAME (not re-read) |

The report form is `DEFECT:コード  file:行 [section か *** cut]  原因。直し方: …` (one per line, in the author's vocabulary). A defective section is dropped and compile continues; marks and references naming it are not counted as collateral defects. With similar names / keys, `似た名: a, b`. Levels: DEFECT (cannot draw; compile stops) / severe (draws but breaks = `overflow occluded offcanvas`) / warn (the engine changed a written value, or it loses in judging = `overridden shrunk transition_over_speech`) / info (reference = `Z_CHILD substituted long_still`). Whether something is fixed is decided by the ledger's fix column, not the level; `lint off=` silences the warn / info of the ledger's mutable rules. Codes: `VERSION TAB INDENT NAME TAG UNIT COLOR QUOTE ARG KEY KEY_DUP REF ROOT_AFTER_CUT DUP_NAME DUP_CUT CUT_UNKNOWN CHILD_UNKNOWN CHILD_TYPE NAME_SHADOW TIMES_N_FRAME FOLD TRANSITION_PLACE FADE_MARK BEAT_BEFORE_CUT BEAT_AFTER_CUT BEAT_OVERLAP NOT_OPEN RANGE SVG_VIEWBOX ASSET_AMBIGUOUS RUN_UNKNOWN ICON_UNKNOWN SHAPE_UNKNOWN EASE_UNKNOWN CAST_KIND CSS`; check's layout breaks are severe `overflow occluded` (a fit the engine could not solve — draws but breaks). Determinism: asset ids and font pins live in `src.json` (`asset_pins`). check resolves ambiguous descriptions and writes them into the pins. A src describing an unpinned asset is not deterministic.

Easy to get wrong (check turns these into DEFECTs, costing a 10〜15 s fix round trip — in order of frequency in staff versions):
- Effect keys (`punch` `shake` `pulse` …) are duration= rotation= pivot= scale= only. `stagger` exists only on appearances (`[>#c[*] {stagger:{each:0.08}}]`) and inside entrance tweens
- `to` keys are x= y= (px from base) left= top= cx= cy= (destinations) width= height= (size) scale= (factor) rotation= opacity= … — in objects `{width: 300}`; only text interpolates `color` (`to,{color}` on other elements is DEFECT — icons / shapes use `recolor,色`; fills use `backgroundColor`); a number tween `to,{textContent: 1231, snap: {textContent: 1}}` (`innerText` too) is a recount (`text,"[count:1231]"`); `set,{opacity: .38}` (GSAP's `tl.set`) is a zero-length `to` (write no duration — the pose at time 0 belongs in declarations); a tween's `filter: 'blur(6px)'` is `blur: 6`; grading filters may be written as CSS on a picture's (img / svg / bg) in / out / main (`in: {filter: 'grayscale(1)', duration: .8}` = a from arriving from the written grading at the static filter; `out: {filter: 'brightness(0)'}` = from static to the written grading; `main: {filter: ['hue-rotate(0deg)', 'hue-rotate(-25deg)'], ease: 'none'}` = a one-shot ramp; `[from, to]` is main only. hue-rotate interpolates in angle steps (saturation does not thin mid-way); a main hue with no duration caps at 45°. Grading on text, shapes, per-glyph (stagger) and periodic waveforms is DEFECT — text color is `to,{color}`; grading an element with children applies to the sheet, children included (the group)); `immediateRender` is read and discarded; color values work as in declarations: `rgba()` `hsl()` color names `var(--x)` too; there is no `xPercent` / `yPercent` (own size × N% into px `x:` / `y:`); there is no GSAP `keyframes` (use `keys(…)`). `in:` / `out:` tweens have no width channel (stretching is `scaleX` + `pivot: 'left'`)
- `flip:` is for named icons and photos / pictures / svg only (not text or boxes)
- A box that bakes a fill (a div with `background:`) needs both width and height (easily lost when a `def`'s `p` is swapped for a div)
- Only children of a parent (div / group) indent. Never indent the line of an element with no parent
- Companions (cards and stamps riding a parent via `overlap: 親`) must appear on a word before the one that moves the parent. Showing and moving on the same word is DEFECT
